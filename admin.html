🔔 Push Notifications — Άμεση Αποστολή

Στείλε push notification απευθείας στις συσκευές των πελατών που έχουν ενεργοποιήσει τις ειδοποιήσεις. Δεν χρειάζεται SMS — εμφανίζεται κατευθείαν στην οθόνη τους.

✅ Χρησιμοποιεί τον Cloudflare Worker σου (FCM V1 API). Δεν χρειάζεται server key εδώ — αρκεί το Worker URL από τις ρυθμίσεις Email παραπάνω.

📱 Μαζικό SMS — Brevo API

Στείλε SMS μαζικά σε πελάτες μέσω Brevo. Κόστος ~€0.04-0.07/SMS. Το κείμενο μετατρέπεται αυτόματα σε κεφαλαία (GSM-7) για 160 χαρακτήρες ανά SMS.

⚠️ Χρέωση: Κάθε SMS χρεώνεται ξεχωριστά μέσω Brevo credits. Βεβαιώσου ότι έχεις αρκετά credits πριν στείλεις.

⏳ Εκπνοή Πόντων

Μηδενισμός πόντων για πελάτες που δεν έχουν επισκεφτεί το κατάστημα τους τελευταίους 12 μήνες. Καταγράφεται συναλλαγή τύπου «Εκπνοή» για κάθε πελάτη.

📉 Tier Downgrade

Μείωση tier κατά 1 επίπεδο για πελάτες χωρίς καμία αγορά στο τρέχον ημερολογιακό έτος. Τα lifetime points μειώνονται στο max του κατώτερου tier.

🔧 System Health Check

Ολοκληρωμένος έλεγχος βάσης δεδομένων, Worker, Service Workers, και ακεραιότητας συστήματος.

Πάτα «Εκτέλεση» για πλήρη διαγνωστικό
BACKUP & ΕΠΑΝΑΦΟΡΑ

💾 Εξαγωγή Backup

Εξαγωγή όλων των δεδομένων σε αρχείο JSON. Συνίσταται τουλάχιστον εβδομαδιαία.

✅ Φύλαξε το αρχείο σε ασφαλές μέρος (cloud, USB).

📤 Επαναφορά Backup

Επαναφορά από αρχείο JSON. Δεν διαγράφονται υπάρχοντα δεδομένα — προσθέτονται μόνο νέα.

⚠️ Αν υπάρχουν ίδιες κάρτες θα παραληφθούν αυτόματα.

🗑 Αιτήματα Διαγραφής (GDPR Art. 17)

Πελάτες που ζήτησαν οριστική διαγραφή λογαριασμού από την εφαρμογή. Η διαγραφή είναι μη αναστρέψιμη — ελέγξτε πριν εκτελέσετε.
